# Project working agreement

- Treat the user interface as mobile-first. New and changed screens must work comfortably in mobile browsers at 320 px and above, with touch-friendly controls and no required horizontal scrolling for primary workflows.
- Do not push, pull, clone, deploy, or modify the live server unless the user explicitly asks for that operation in the current conversation.
- Keep production secrets out of tracked files. Configure credentials through the ignored `.env` file during deployment.
- Preserve the existing Turkish interface language unless the user requests another language.
